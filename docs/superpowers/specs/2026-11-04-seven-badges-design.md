# 虫洞穿越：七枚徽章与分阶段奖励

状态：设计提案，未接入游戏或官网。2026-11-04。沿用用户提供的立体金属徽章参考，独立创作太空图案。本文件替代旧版六彩蛋清单，旧文档保留作历史。

## 七枚徽章

| 名称 | 条件 | 图案 |
| --- | --- | --- |
| 失落的回声 | 体验关或第1关：漏第3环，命中第4、5、6环，完整完成本局 | 断开的星门与回声弧 |
| 绝境归航 | 一局前3环全部漏过，最后5环全部命中，中间不限，完整完成本局 | 从暗处升起、驶向星光的飞船 |
| 最后一束光 | 一局前面所有环全漏，只命中最后1环，完整完成本局 | 一列暗星与唯一亮起的终点 |
| 双星共振 | 相邻两关全中，经“下一关”接续 | 双星门交叠 |
| 虫洞密码 | 连续三局完整人工航行，漏环数按顺序恰好为3、1、4；关卡实际门数不限 | π与三层轨道 |
| 百门之外 | 同一玩家跨已完成有效局累计命中至少100环 | 百环星路与远方航线 |
| 母港来信 | 完成第20关，最后3环全中 | 母港信标与返航飞船 |

虫洞密码不是命中3、1、4，而是分别漏过3、1、4环。例如三局各12环时，命中9、11、8；门数变化时，按实际总环数减去3、1、4计算。3·1·4来自圆周率π开头，与环形星门呼应，是游戏暗号，不是虫洞物理常数。可自由选关/重玩连续组成三局，不要求三个相邻关卡；但演示、放弃本局、切换玩家会打断密码序列。连续记录取最近三局，有效序列3、3、1、4可在末三局达成；不能挑三次不连续结果拼接。

双星共振的顶部24只作为第1、2关各12环的设计示例，不是所有相邻关的固定总数；最终生产美术宜改成双星符号，避免误导其他关卡。当前生图为概念板。

## 统计与恢复

每位玩家每种徽章只获一次，自动演示不计入。环事件按实际顺序处理，单局结果只结算一次。全部条件以完整结束本局为正式解锁时点。暂停/恢复同一局不重计；进度读取失败不能假装恢复成功。

建议支持本机继续航行，保留玩家进度、已结算累计与徽章、当前局状态和跨关连击；恢复前2秒重新校准，不计算离开期间的飞行时间。此存档与恢复功能仍需单独实施及宿主存储验收，当前1.4.4尚无此功能。共享眼镜须有“换位领航员”并确认清空当前玩家，防止不同观众拼接成就。未来跨设备持有与官网身份绑定另行设计。

3连、5连与每10连烟花作为常规反馈，不占七枚徽章；烟花只在视野外围，不能盖住光门。难度、飞行物理与分数不因徽章改变。

## 奖励阶段建议（待用户定奖品）

| 阶段 | 建议门槛 | 候选奖励形式 |
| --- | --- | --- |
| 初航纪念 | 任意1枚 | 一张可下载太空纪念图 |
| 星际探索者 | 任意3枚 | 数字画集/壁纸组等数字奖励 |
| 王牌领航员 | 至少5枚，且含双星共振或母港来信至少一枚 | 小型实物礼品候选档 |
| 全徽章收藏 | 全7枚 | 专属收藏证书、特别数字藏图或更高一档礼品候选 |

七枚集齐不作为所有奖品的唯一入口。最后一束光、虫洞密码需刻意控制漏环，不直接等同高操作水平；单枚隐藏徽章不直接绑定高价值奖。实物档增加挑战徽章门槛，避免只靠刻意漏环获得高手档奖励。具体礼品、价值、名额和库存仍由用户决定；未定奖品时不对玩家承诺实物可领。

同一阶段不重复领取，领奖不消耗徽章、不清掉游戏进度。阶段可逐步升级，是否采用奖品补差/升级替换或允许各档分别领取，需结合最终预算确定后再发布活动规则。

## 网站领奖路径草案

游戏获得徽章 → 玩家到官网同步并核验资格 → 展示已达奖励阶段 → 选择领取 → 官网签发该奖励的一次性兑换码 → 兑换码确认/兑换 → 数字奖励直接下载，实物奖励填写收件人/电话/地址并确认 → 生成领取记录/寄送状态 → “探索更多AIUI”。

兑换码表示服务端已核验的奖励资格，不是进入官网后随便生成的凭证。重复提交同一码应回到原领取记录，不重复扣库存或新建寄送单。游戏到官网的可信资格关联方式尚未设计，不能以截图、可修改的本地徽章数据或静态二维码作为高价值实物的唯一核验依据。此处是接口边界，不是已上线系统。

数字图奖励不要求填写邮寄地址。仅实物领取时收集寄送所需信息，展示确认页，邮寄信息不回写眼镜。领取完成后立即给出“查看我的奖励/寄送记录”与“探索更多AIUI”两个清晰入口；更多AIUI作为后续自愿探索，不阻塞领取。

官网尚未上线期间，游戏文案仅“徽章已解锁，领奖活动尚未开放”，不生成伪兑换码、不使用虚构URL。
