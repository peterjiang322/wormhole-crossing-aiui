# 虫洞穿越：商场路演展示设计

用户已认可头动透视穿门方案，并授权直接开发、少关卡、短时长、独立GitHub仓库。

娱乐展示，面向2026年11月27—29日商场路演的初次佩戴者。最短链路：戴好眼镜→点头/点击开始→2秒正视校准→45秒飞行→成绩→再来一次。只有一个关卡，12个光门。开局5秒用宽门引导，最后5秒进入跃迁视觉收尾；不因失败中断。

Canvas 2D绘制真实三维点的透视投影；姿态旋转虚拟相机，小幅偏航/俯仰同时引导飞行路径。近景隧道、分层星点、八边光门、仪表与穿门粒子使用单绿色#40FF5E及透明度。不是双目立体、空间锚定或6DoF跟踪。不使用WebGL或CSS动画。

默认菜单横排并复用官方本机skill菜单控制器、完整点头确认。游戏内持续头动输入和菜单传感器互斥。绝对姿态优先，校准时以当前朝向为原点；不可用时显式降级陀螺仪短时积分，读数断流暂停并显示原因，允许显式重试或按键模式。允许校准重置和分别反转左右/上下轴。无传感器时保留方向键，观赏演示独立标识且不计真实成绩。菜单横滚按数值scroll-left执行。

纯离线规则游戏，无模型、语音输入、拍照、联网、用户账号或隐私采集。AIUI是运行平台，不把规则得分宣传为AI判断。无开放问答，追问上限0；无需ASR/TTS切换。成绩仅当次内存，回首页清除；方向/音效设置仅当前会话。游戏评级由命中数决定，并显示命中/总数、分数、最佳连击；反馈为重玩或回首页。

phase为ready/calibrating/flying/paused/result/error。隐藏时终止传感器、计时器和音效并取消本局；恢复回首页，旧回调不得落地。传感器启动超时2秒，断流1秒暂停；Canvas尝试20次后显式报错，不假装成功。校准阶段记录最新有效姿态，到飞行时再次置零以消除开始点头残留。

目标448×352逻辑画布、约20fps，HUD文本最多5Hz更新；按键/点击反馈目标200ms内，真机需记录实际帧率与头动延迟。每人原地小幅转头，避免要求走动/大幅甩头；无强制翻滚或闪烁。按键/点击可暂停，返回键遵循宿主默认退出。
