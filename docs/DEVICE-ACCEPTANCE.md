# Rokid真机与路演验收

## 记录环境

验收时记录实际Rokid型号、固件、Ink版本、安装包SHA和现场光照。当前没有连接设备，下面是交付后的设备验收步骤，不是已通过的结果。

## 佩戴者流程

1. 导入最新AIX或源码包，确认首页「星门穿梭」及三个可见横排按钮，无裁切；向右到第四项「按键模式」，再回第三项，焦点和视窗一致。
2. 左右轻轻转头只换菜单；完整点头回正只执行一次开始，静止低头不能执行；点击和确认键同样能开始。
3. 正视前方2秒，确认校准稳定，不把开始点头残留当转向。轻转左右、轻抬低头，光门和隧道透视应立即变化，方向符合身体动作。反向时在设置中分别反转相应轴。
4. 运行整局45秒+2秒校准；检查首门引导、12门命中/漏门、连击音效和最后5秒跃迁收尾。漏门不得中断，成绩解释与重玩正常。
5. 中途点击重置朝向，当前方向应归中；暂停后转头不会继续计时。继续时重新校准，保留已获得的正式成绩。
6. 头动不可用/权限拒绝/无读数应显示错误或暂停，不假装跟踪。按键模式可继续；自动演示必须明确标识，转手动重新开局。
7. 运行中按返回/双击退出，重新打开回到首页；隐藏后不持续采样/播放音效/计算旧局。连续换三位体验者不继承前一位成绩或姿态原点。

## 现场验收目标

- 小幅转头约左右15°、上下10°即可操控，不要求走动或大幅甩头。
- 初次佩戴者10秒内理解操作，一次体验约47秒，单人原地使用。
- 目标20fps和头动到画面更新200ms内；按目标设备实际测量记录，低于目标时先降星点/隧道环数量，不改变45秒墙钟。
- 商场明亮背景仍能辨识门与准星；若背景干扰，调整展位朝向或降低环境亮度，不声称黑色能遮挡现实。
- 核验本地音效路径是否受目标宿主支持；失败时画面照常运行，提示音效不可用，可关闭音效。
